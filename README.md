# Factur-IA d'escriptori

Instal·lador i actualitzacions de **Factur-IA**, l'extractor de factures i nòmines d'UNIAUDIT Oliver Camps (UNOC), en la versió per a ordinador **sense IA**: extracció per zones, Excel i documents amb les zones marcades. Els documents no surten de l'ordinador.

Aquest repositori només conté els arxius publicats de cada versió. No hi ha codi font ni cap document.

## Instal·lar

1. Obre la [darrera versió](../../releases/latest) i baixa `Factur-IA-<versió>.msi`.
2. Obre l'arxiu. S'instal·la per a tu, sense permisos d'administrador, i crea accessos directes a Inici i a l'escriptori.
3. Si Windows avisa que ha protegit l'ordinador: «Més informació» › «Executa igualment».

Si l'instal·lador no funciona al teu ordinador, baixa el `.zip` portable, extreu-lo i obre `Factur-IA/Factur-IA.exe`.

## Actualitzacions

L'app busca versions noves cada vegada que s'obre (també a Ajuda › «Cercar actualitzacions…»). Les baixa d'aquí, en comprova la signatura i les fa servir la propera vegada que l'obres. L'historial es conserva.
